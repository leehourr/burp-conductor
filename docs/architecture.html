scoping · recon · auth · access · inject · roundout · report

Every phase calls into the shared tool surface above — Burp MCP's 26 tools plus the free stack invoked via Bash — and every call passes through the safety spine below before it leaves the host. The lifecycle is linear by design: scope is locked before recon, recon seeds the verify queue that auth / access / inject / roundout work through, and nothing fires at an upstream target without an explicit human go.
